# CI/CD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GitHub Actions CI(테스트·빌드 자동화) + GitHub Pages 자동 배포 워크플로우를 추가한다.

**Architecture:** 두 개의 독립 워크플로우 파일을 생성한다. `ci.yml`은 모든 push/PR에서 테스트·빌드를 실행하고, `pages.yml`은 main에 `scan-result.json`이 변경될 때만 HTML 리포트를 생성해 GitHub Pages에 배포한다. `.gitignore`에 `scan-result.json` 예외를 추가해 결과 파일을 git으로 추적한다.

**Tech Stack:** GitHub Actions, Node.js 20, `actions/checkout@v4`, `actions/setup-node@v4`, `actions/upload-pages-artifact@v3`, `actions/deploy-pages@v4`

```yaml
  push:
    branches: ["**"]
  pull_request:
    branches: [main]

  ci:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4

          cache: npm

      - run: npm run build
```

## Task 2: Pages 배포 워크플로우

**Files:**
- Create: `.github/workflows/pages.yml`

- [ ] **Step 1: `pages.yml` 작성**

`.github/workflows/pages.yml` 파일 생성:

```yaml
name: Deploy Portfolio Report

on:
  push:
    branches: [main]
    paths:
      - .portfolio-tracker/scan-result.json

permissions:
  pages: write
  id-token: write

jobs:
  deploy:
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deploy.outputs.page_url }}
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm

      - name: Install and build
        run: npm ci && npm run build

      - name: Generate HTML report
        run: node dist/cli/index.js export -f html -o _site/index.html --all

      - name: Upload Pages artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: _site

      - name: Deploy to GitHub Pages
        id: deploy
        uses: actions/deploy-pages@v4
```

- [ ] **Step 2: YAML 문법 검증**

```bash
node -e "
const fs = require('fs');
const content = fs.readFileSync('.github/workflows/pages.yml', 'utf-8');
if (!content.includes('on:') || !content.includes('jobs:') || !content.includes('permissions:')) {
  throw new Error('Invalid workflow structure');
}
console.log('YAML structure OK');
"
```

Expected: `YAML structure OK`

- [ ] **Step 3: CLI 빌드 확인**

```bash

```

Expected: 빌드 성공, 버전 출력 (`0.1.0` 등).

- [ ] **Step 4: 커밋**

